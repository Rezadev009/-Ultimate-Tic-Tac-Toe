# -Ultimate-Tic-Tac-Toe
A multilingual Tic Tac Toe game built with Python and Pygame
🎨 Modern and dark user interface

👥 Two-player mode

🤖 Play against the computer

🧠 Smart AI powered by the Minimax algorithm

🌍 Supports 5 languages:

English

Persian

German

French

Spanish

🏆 Score tracking

🔄 Restart and return to main menu

🎯 Automatic win and draw detection

🛠️ Technologies

Python

Pygame

Arabic Reshaper

Python Bidi

📦 Installation

Install the required libraries:

pip install pygame arabic-reshaper python-bidi

▶️ How to Run

Run the main Python file:

python "Tic Tac Toe.py"

🎮 Game Modes

Two Players: Play with a friend.

Play vs Computer: Challenge the computer using the Minimax algorithm.

🌐 Languages

Choose between five languages directly from the game menu.
